MySQL essentials

Core database concepts used in this project.

01 / BASICS

What is MySQL?

MySQL is a relational database management system (RDBMS). It stores data in tables made up of rows and columns and uses SQL to work with that data.

02 / KEYS

Primary & foreign keys

A primary key uniquely identifies a row. A foreign key links a column in one table to a key in another table and helps preserve referential integrity.

03 / RETRIEVE

SELECT and WHERE

SELECT product_name, price
FROM products
WHERE price < 2000
ORDER BY price;

SELECT retrieves columns, WHERE filters rows, and ORDER BY sorts the results.

04 / CHANGE DATA

INSERT, UPDATE, DELETE

INSERT INTO products
(product_name, category, price, stock)
VALUES ('USB Cable', 'Accessories', 250, 15);

UPDATE products SET stock = 20
WHERE product_id = 1;

DELETE FROM products WHERE product_id = 9;

Always use a WHERE condition with UPDATE or DELETE when you intend to change only selected records.

05 / SUMMARY

Aggregate functions

SELECT COUNT(*) FROM products;
SELECT AVG(price) FROM products;
SELECT MAX(price) FROM products;
SELECT SUM(stock) FROM products;

COUNT, AVG, MAX, MIN and SUM calculate summaries over a set of rows.

06 / CONNECT

How this website works

HTML displays forms and tables. Flask receives requests and runs Python code. The MySQL connector sends SQL queries to MySQL, and the returned records are displayed in the browser.
